# pixelcat-generator
 This is a small python code that generates random pixel cats (the same cats as on my avatar here!!)
## Description
arts.py - the module in which the random generation of the cat occurs, contains the function of drawing and clearing what was drawn. When generating a cat, the program randomly collects its palette and randomly selects its shape.

gener.py - the main file in which you can request the generation of cats. The two functions written in the arts.py module are used here. The code saves the cats to a specific folder. Three lines for displaying the generated cats are still hidden by comments - I’m not Elon Musk to launch other people’s computers into space... (however, with a small number of generated cats, everything works and no one flies anywhere (my laptop could not cope with opening the windows with all the cats - a maximum of 6 were open, creaking with microcircuits, the rest of the windows opened, but the cats were not displayed due to the gallery crashing)).

pixels - a folder with text files that store cat options for generation.

collection - the very specific folder in which the cats are saved (there are 36 cats in this folder).
